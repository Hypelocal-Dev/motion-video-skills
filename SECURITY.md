# Security

The plugin runs local scripts and installs Python packages into `~/.motion-video/venv`.
It doesn't send your files anywhere. HyperFrames and Kokoro run locally. The only
downloads are the models HyperFrames fetches on first use.

To report a vulnerability, use
[GitHub's private vulnerability reporting](https://github.com/tjdotwal/motion-video-skills/security/advisories/new)
rather than a public issue. You'll get a reply within a week.
